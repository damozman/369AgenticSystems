# Brand assets

Where the non-code brand material lives, and the copy that goes with it. Recorded here because
the copy existed only in a loose `.txt` next to a video file on a desktop, which is one accidental
folder deletion away from gone.

## Brand video 01

**Caption / post copy** — verbatim, as written 2026-07-26:

> **Invisible Infrastructure. Visible Scale.**
>
> We architect intelligent systems that run your business for you — answering every call,
> qualifying every lead, booking every appointment.
>
> Live in 24 hours.
>
> Book a Free Audit → 369agenticsystems.com

**The video file itself is deliberately not in this repo.** It is ~5MB of MP4, and binaries in
git are permanent — every clone pays for them forever, and a re-cut means carrying both. Keep it
in cloud storage (Drive, Dropbox) alongside the rest of the raw brand material. If it ever needs
to be served from the site it belongs in `public/`, where Vercel's CDN handles it, not in a doc.

### Accuracy notes if this copy is reused

Two claims in it are load-bearing and worth re-checking before it goes anywhere new:

- **"Live in 24 hours"** matches the current onboarding promise. The site says the same thing in
  several places. If provisioning ever slows down, this line changes with it.
- **"booking every appointment"** became literally true on 2026-08-06, when Google Calendar sync
  shipped and was proven on a real call — Ava now reads the owner's calendar before offering a
  time and writes the event after booking. It was aspirational when this caption was written.

There are no borrowed or third-party statistics in this copy, which is why it survives the
standing rule against them. Keep it that way.
