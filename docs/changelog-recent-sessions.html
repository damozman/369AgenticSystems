3. Real-Call Debugging Rounds

34a7601, a64ad8e, 1d68bbf

Four consecutive real-phone-call test rounds, each surfacing a genuine bug the previous round missed.

Retell's actual tool-call payload shapeFixed

Retell POSTs {call, args}, not a flat body — capture-lead/book-appointment were silently failing on every real call until unwrapped correctly.

Duplicate lead rowsFixed

The model sometimes called capture_lead twice with incomplete args each time — second call nulled out the first's data. Fixed with upsert-on-call_id + a new unique constraint.

Dead air during tool callsFixed

Ava went silent while capture_lead/book_appointment ran, callers thought the line dropped. Added filler speech.

Email/issue description unreliable — 3 calls in a rowFixed

Prompt-wording fixes didn't hold. Root fix: added these fields to Retell's async post-call analysis and backfill from there whenever the live call missed them — two independent extraction passes instead of one fragile one.
