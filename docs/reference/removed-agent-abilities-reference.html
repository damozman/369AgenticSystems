Round 3 — 2026-07-11 Pricing Page

the paid product itself, not marketing copy

Rounds 1 and 2 were both marketing-page overclaims — landing pages, agent bios, hero copy. This one is different in kind: lib/tier-config.ts is the actual file that drives the real pricing page and Stripe checkout. Its Pro and Elite tier feature lists promised capabilities that don't exist anywhere in the codebase, presented as plain included-feature checkmarks with no "planned" qualifier (the pricing component has no such qualifier system to begin with). Caught while writing docs/architecture/WHAT-CAN-I-DELIVER-TODAY.md — no customer impact yet since Stripe is still test-mode, but this would have been a real broken promise the moment a client paid for Elite expecting review automation.

Pro tier ($600/mo)Sold as included, not built

"Lead scoring & prioritization," "Conversion tracking," "Advanced reporting" — zero implementation anywhere in the codebase.

Pro's one real differentiator over Starter: Rex's automated follow-up sequence (live for roofing/HVAC/plumbing, planned elsewhere). Feature list rewritten to "Automated lead follow-up sequence," plus two real, previously-unlisted Retell platform features (Enhanced Voice Quality) and a service-level commitment (priority email support).

Elite tier ($750/mo)Sold as included, not built

"Review request automation," "AI review response drafting," "Reputation score monitoring," "Referral tracking" — none of this exists. Confirmed against the client dashboard's own code comment: Nova doesn't do review requests for any vertical, and the "reviews" agent key is hardcoded to always show "deploying," never "live."

No review-platform integration, no reputation monitoring, no referral tracking exists or is scheduled. Feature list rewritten to the two real bundled Retell features Elite actually gets (Premium Voice Quality, Custom Business Intelligence) plus priority onboarding/support. Elite's agents array also had a phantom 'reviews' entry removed — that field isn't rendered on the pricing page itself, but was still inaccurate metadata worth correcting.

Also found and left alone (dead code, not currently exploitable): PREMIUM_ADDONS in the same file — Live Call Transfer, Branded Caller ID, Spanish Support, Custom Voice, HIPAA Pack, $29–$99/mo each — defined but never imported or rendered anywhere in the actual pricing UI. Not sellable today. Flag before ever wiring it up.
