# docs/

- **`architecture/`** — current system blueprint (`369-SYSTEM-BLUEPRINT.md`) and the sales-facing ground truth (`WHAT-CAN-I-DELIVER-TODAY.md`, tier-by-tier and vertical-by-vertical, updated whenever real capability changes). Start here for "what is this business and how is it built" or "what can I actually sell right now."
- **`sales-ops/`** — sales playbook, discovery/demo/close scripts, contract template. Active, in-use material.
- **`reference/`** — operational reference docs: QA runbook, session changelog, the running list of fictional-claim fixes from truthfulness sweeps.
- **`possibilities/`** — later-phase ideas, parked for review when there's bandwidth. Not commitments.
- **`sop/`** — standard operating procedures, to be filled in.
