# docs/

**Start here each session: the Session Handoff section at the top of `CLAUDE.md`** (repo root)
for current working state, then **`architecture/WHAT-CAN-I-DELIVER-TODAY.md`** for what is
actually deliverable — per vertical, and what each one still needs.

**Corrected 2026-08-19:** this file used to send you to `ROADMAP-TO-REAL-AGENCY.md` as the living
tracker. It stopped being maintained on 2026-07-16 and is now bannered as a historical record, as
are the blueprint and the questionnaire plan. Following the old instruction meant starting each
session from a month-old picture that predates calendar booking, rental inventory, usage billing,
AI disclosure and A2P.

- **`architecture/`** — **`WHAT-CAN-I-DELIVER-TODAY.md` is the only current doc here**: what ships
  today vs what does not, per vertical, with what each gap needs. Open it before a sales call or a
  chamber event. The other three (`ROADMAP-TO-REAL-AGENCY.md`, `369-SYSTEM-BLUEPRINT.md`,
  `ONBOARDING-QUESTIONNAIRE-AND-KB-PLAN.md`) are **stale by design** — dated records of why things
  were built the way they were, each carrying a banner listing its known-wrong claims.
- **`sales-ops/`** — sales playbook, discovery/demo/close scripts, contract template. Active, in-use material.
- **`reference/`** — operational reference docs: QA runbook, session changelog, the running list of fictional-claim fixes from truthfulness sweeps.
- **`possibilities/`** — later-phase ideas, parked for review when there's bandwidth. Not commitments.
- **`sop/`** — standard operating procedures, to be filled in.
