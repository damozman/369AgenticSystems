# docs/

**Start here each session: `architecture/ROADMAP-TO-REAL-AGENCY.md`.** It's the
living build-priority tracker — what's done and verified, what's built but
unverified, what's next, in order. Everything else in this folder is either a
companion to it (below) or a dated, point-in-time historical record — read
those for context on a specific past decision, not as a starting point.

- **`architecture/`** — `ROADMAP-TO-REAL-AGENCY.md` (start here, see above), the current system blueprint (`369-SYSTEM-BLUEPRINT.md`), and the sales-facing ground truth (`WHAT-CAN-I-DELIVER-TODAY.md`, tier-by-tier and vertical-by-vertical, updated whenever real capability changes — open this one specifically before a sales call).
- **`sales-ops/`** — sales playbook, discovery/demo/close scripts, contract template. Active, in-use material.
- **`reference/`** — operational reference docs: QA runbook, session changelog, the running list of fictional-claim fixes from truthfulness sweeps.
- **`possibilities/`** — later-phase ideas, parked for review when there's bandwidth. Not commitments.
- **`sop/`** — standard operating procedures, to be filled in.
